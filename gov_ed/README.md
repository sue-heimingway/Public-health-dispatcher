# GovOS · 社会治理诉求分流中枢

> 把急诊分诊系统的「6 个 Agent 框架」整体平移到社会治理：
> 框架不变（采集 → 排雷 → 定级 → 质控 → 追踪 → 通报），知识库和判定规则全部换成政务语境。

```bash
cd gov_ed
py -3 run.py            # 自动开浏览器 http://127.0.0.1:8780
```

零依赖（Python 3.10+ 标准库），断网可跑。

> ⚠️ **演示原型**：仅用于流程演练，不构成真实政务处置依据，不替代人工审批。

---

## 零、混合架构（对齐"词元工厂"大模型主题）

```
大模型  ── 诉求抽取 / 情绪识别 / 通报话术生成（语义理解、表达）
规则引擎 ── 四级响应分级 / 社会风险排雷 / 质控安全底线（可解释、可复现、不漏报）
人在环  ── 最终裁决（高危 / 分歧 / 舆情升级）
```

**一句话定位：大模型做理解，规则做兜底，人做决策。**

- 配置 `DEEPSEEK_API_KEY`（或 `OPENAI_API_KEY`）后，Agent ① 的诉求抽取与 Agent ⑥ 的通报生成
  自动升级为大模型增强（工作台卡片会标「⚡大模型」，顶栏显示「大模型：已接入」）；
- 分级、排雷、质控这**安全核心永远走规则**——保证 100% 可解释、可复现、不漏报；
- 无 Key、断网、超时、返回非法 JSON 时，**自动静默降级为纯规则**，主流程永不中断。

```powershell
# Windows 一次性设置（然后重开终端）
set DEEPSEEK_API_KEY=sk-xxxx
py -3 run.py
```

## 二、六个 Agent 的「平移对照」

| # | 急诊临床版 | 社会治理版 |
|---|---|---|
| ① | 懂医学术语：把「肚子像刀割」提取成急腹症 | 懂政务诉求：把「救命啊买不到退烧药」提取成**物资短缺**；把「老人发烧喘不上气」提取成**重症就医**，并自动抓**地址** |
| ② | 懂致命病（夹层、宫外孕） | 懂社会高危：**传染病聚集爆发？恶意制造恐慌？群体性事件苗头？** |
| ③ | 按 ESI 分 1–4 级 | 按**政务响应等级**分级：一级危及生命转 120/110；二级恐慌转宣传部/网信办；三级派单；四级自动答复 |
| ④ | 防漏诊、防给错级 | 防**误判与次生舆情**：市民恐慌时机械回「请耐心等待」→ 立刻拦截改温和安抚 |
| ⑤ | 患者扫 H5 反馈「更痛了」 | **舆情热点追踪**：多人跟帖「我们小区也断药了」→ 自动重新评估并升级 |
| ⑥ | 给暴躁家属解释「为什么先救别人」 | **政务通报与情绪安抚生成器**：官方、有人情味、不失原则的通报，一键推送 |

两个底座：
- **底座 1**：政务诉求语义库（`app/lexicon.py`）——40+ 诉求类型 + 情绪/地址/人数抽取
- **底座 2**：Human-in-the-loop（`app/store.py` 工单 + `/duty`）——P0/P1 工单、SLA、审计留痕

安全原则与急诊版一致：**Agent 只自动升级、不自动降级**；降级必须由人做并写理由。

## 三、四级政务响应

| 等级 | 触发 | 处置通道 |
|---|---|---|
| 一级（红） | 危及生命/安全（重症求助、燃气火灾、坍塌、中毒、聚集疫情） | 转 120/110/119 + 属地立即到场 |
| 二级（橙） | 舆情/恐慌/群体苗头（谣言抢购、聚集维权、欠薪讨薪） | 转 宣传部/网信办/政法 |
| 三级（黄） | 具体诉求（物资短缺、物价、环境、物业、市政） | 派发责任部门工单，限时办理 |
| 四级（蓝） | 政策咨询/一般 | 自动答复闭环 |

## 四、10 类社会风险（Agent ② 排雷清单）

危及生命/安全、传染病聚集爆发、群体食物中毒、校园安全隐患、群体性事件苗头、谣言恐慌传播、独居老人急难、物资药品短缺（抢购）、欠薪聚集讨薪、次生舆情风险。

## 五、演示案例（7 个）

| # | 诉求 | 预期 |
|---|---|---|
| ① | 老人发烧喘不上气 | 一级，转 120+属地，P0 |
| ② | 小区多人发烧咳嗽 | 一级，传染病聚集线索，P0 |
| ③ | 群里传药要断供+抢购 | 二级，谣言恐慌，转网信/宣传 |
| ④ | 农民工讨薪要拉横幅 | 二级，群体性苗头，转政法/信访 |
| ⑤ | 恐慌中问医保 | 裁判四级 → **质控拦截升级二级**（次生舆情演示） |
| ⑥ | 买不到退烧药（无恐慌） | 三级工单，不误升级 |
| ⑦ | 咨询医保报销 | 四级自动答复，0 工单 |

**最有说服力的场景**：⑤ 恐慌问医保——裁判按规则判四级（政策咨询自动答复），
质控因「情绪恐慌」把安全底线压到二级并拦截「机械冷回复」，自动生成温和人工回应。

## 六、接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/state` | 队列 + 工单 + 统计 |
| GET | `/api/case/<id>` | 单个诉求全景（六 Agent 卡片） |
| GET | `/api/report/<token>` | 市民端视图 |
| POST | `/api/intake` | 受理并跑完 ①~⑥ |
| POST | `/api/report` | 市民补充反馈 → 触发 ⑤ 重新评估 |
| POST | `/api/hitl` | 值班处置：agree / upgrade1 / upgrade2 / downgrade / missing / accept |
| POST | `/api/demo/seed` / `/api/reset` | 填充队列 / 清空 |
